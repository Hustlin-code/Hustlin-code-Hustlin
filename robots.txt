# Gated shell. Serves no lesson content to crawlers — every lesson is fetched
# from an authenticated Edge Function.
#
# FIXED 2026-08-08 — "Disallow: /learn.html" is GONE. It was the cause of the
# Search Console error on https://hustlin.org/learn.html?course=fl&stage=1:
# "Page cannot be crawled: Blocked by robots.txt".
#
# That URL is not supposed to be indexed — but it IS supposed to be crawled,
# because learn.html carries a first-in-head redirect that sends ?course=fl
# straight to the static /stage-N-*.html page. That redirect is the entire
# mechanism that consolidates the two duplicate URLs into one. A Disallow
# stopped Googlebot fetching the file, so it never executed the redirect and
# never saw the noindex either. The old FL URL just sat in the index as a
# bare, description-less entry, holding link equity that could not flow
# anywhere — exactly the failure mode already documented for /Markets/ below.
#
# noindex (already on the page) is the correct tool and is now the only one
# acting on it. Google can fetch, follow the redirect to the real stage page,
# consolidate the signal, and drop the shell cleanly.

# Market viewer sub-pages.
#
# CHANGED 2026-08-02 — the blanket "Disallow: /Markets/" is GONE.
#
# It was correct when written: those pages were a TradingView iframe wrapped in
# ~200 words of chrome, and the widget content is not ours to rank for. Four of
# them have since been rewritten with 1,150-1,780 words of original analysis
# each, canonical tags and Article/FAQ schema, and their noindex tags removed.
#
# Leaving this line in place would have quietly wasted all of that: a Disallow
# stops Google FETCHING the page at all, so it never sees the new content and
# never sees the noindex removal either. A page can be blocked by robots.txt
# and still surface as a bare URL with no description — the worst of both.
#
# The three genuinely thin ones are retired redirect stubs. They keep their
# noindex tags, which is the right tool here: crawlable, not indexable, so link
# equity still flows through them.
#
# If you ever add a new thin viewer page, give it a noindex meta tag. Do not
# reach for a Disallow — noindex is what you actually mean.

# a bug, not a permission.
#

# ignores every other group — including "User-agent: *". So naming bingbot here
# to allow it silently exempted Bing from every Disallow rule at the top of this
# file. Bing was free to crawl the gated shell, all seven auth pages, and all
# five raw course-fragment folders: partial HTML files that are not pages and
# read as thin, duplicated junk to a crawler still deciding whether this domain
# is worth its budget.

# there, add it here too — or Bing will not honour it.
